# BlockExplorer

Builds a graphical interface for exploring and visualizing blockchain data in real time for developers and researchers.

The key benefits of using BlockExplorer include:

- Builds a graphical interface for
- exploring and visualizing blockchain data
- in real time for developers

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockExplorer.git`
2. `cd BlockExplorer`
3. Install in editable mode: `pip install -e .`

## Configuration

BlockExplorer is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
